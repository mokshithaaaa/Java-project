# 💬 Java Chat Application

A real-time multi-user chat application built using Java Socket Programming, Multithreading, and Java Swing GUI.

---

# 🚀 Features

✅ Multiple User Messaging  
✅ Real-Time Chat Window  
✅ Notification Alerts  
✅ GUI-Based Interface  
✅ Socket Programming  
✅ Multithreading Support  
✅ Instant Message Broadcasting  

---

# 🛠 Technologies Used

| Technology | Purpose |
|---|---|
| Java | Core Programming |
| Java Swing | GUI Development |
| Socket Programming | Network Communication |
| Multithreading | Handle Multiple Clients |
| Input/Output Streams | Message Transfer |
